## Conventions

- Cross-reference WebForms research using relative links like [../webforms/00-overview.md](../webforms/00-overview.md).
- Annotate every design region with its parity status: PARITY (matches WebForms), MOVED (same content, different position), CHANGED (same intent, different UX), NEW (net-new feature), DROPPED (was in WebForms, intentionally removed).
- Capture screenshots / region annotations as needed; embed inline if small, link to Figma if large.
- Do not use em-dashes or `--`.
